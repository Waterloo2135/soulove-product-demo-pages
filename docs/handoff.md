# 下游 UI 交接模板

方案通过后，按这个结构写到 `D:\\code\\soullove-openspec\\SL\\PRD\\[需求名]PRD.md`。

## 必须写清

1. 作用页面（screen-map 中的路径 / Demo screen id）
2. 作用状态（Guest / Free / Plus）
3. 主路径怎么走，哪里打断
4. 新增/变化的 Overlay、文案、CTA
5. 不改范围
6. Demo 变体路径：`variants/[需求名]`
7. 视觉：UI 可精修；信息架构、付费节奏、主 CTA 不能擅自改

## 不要交给 UI 的东西

- 生产代码实现细节
- 支付渠道 SDK
- PC / SEM / Live-Pro 范围外页面
