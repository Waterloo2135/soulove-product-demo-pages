# 短剧 Remix（v3）

## 入口
- 播放页仅右侧 🎬 Remix；进入前**暂停**短剧播放（PRD 必写）
- 底部入口条仍 hidden 保留

## Creation
- 去掉右上角 My Remixes，只留横条
- 规格按钮：`5s · 480P ›`（无 Tap to edit）
- Generate → My Remixes 瀑布流

## My Remixes
- 2 列瀑布流，竖屏 9:16 / 横屏混排
- 生成中 overlay
- 列表 **Continue ›**；放大查看页底部 **Continue from last frame**
- Continue 以尾帧为起点扩写；生成后**合并**成长片，可再次 Continue

## 文案
- 按钮主文案：Continue（列表 Continue › / 查看页 Continue from last frame）
