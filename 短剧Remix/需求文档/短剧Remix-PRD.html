3. 需求背景

短剧播放后用户想「用剧中角色再生成片段」，但多数人不会写镜头级 prompt。竞品 Flickreels 提供 Remix 创作。Soulove 需要：降低创作门槛、用他人样片做社会证明、用制作行为商业化（不靠看词收费）。

4. 需求目标

  • 从播放页进入 Remix，先看到他人/平台怎么拍，再自己创作或续写。
  • Intent 与运营预设降低不会写 prompt 的成本。
  • 商业化发生在 Generate / Extend 提交，不拦截查看 Prompt。
  • 大尺度样片非会员马赛克，解锁复用 Private photo 会员墙。

成功指标：本期不补埋点与数值目标，待确认。

5. 需求概述

用户在短剧播放页点 Remix → 默认 Inspiration → 可 Create Myself 进 Creation，或对样片 Remix / Extend。自己的成片在 My Remixes，放大播放与 Inspiration 共用样式，可再 Remix / Extend。

本期不做：强制看完灵感才能创作；看 prompt 付费；Extend 他人单独加价；重社区（关注/评论）；底部播放页 Film Scenes 等入口（隐藏保留）。

8. 详细方案

一级模块二级功能原型描述
入口 播放页 Remix short-drama-watch

【页面元素】全屏播放；右侧操作列 🎬 Remix。底部 Film Scenes 等隐藏保留。

【交互说明】1. 点 Remix → 暂停短剧播放。2. 进入 Inspiration。

【功能逻辑】进入 Remix 必须 pause，写入后续实现与 PRD。
默认 Inspiration drama-remix ideas

【页面元素】标题 Inspiration；本剧瀑布流；分割线「More from Soulove」；双列 9:16/横屏混排；底栏悬浮 Create Myself（#ee0097）。

【交互说明】1. 视口内 clip 静音自动播（含模糊条）。2. 点击 clip → 放大播放。3. Create Myself → Creation。

【文案规范】Create Myself；More from Soulove；Extend；Remix。
样片可见性 CMS 模拟

【功能逻辑】每条可配 memberOnly、plats[]。Web Demo 过滤非 web/all。memberOnly 且非 Plus：马赛克仍播放。

【前置条件与权限】点模糊样片走 unlockBlur（与解锁 private photo 同墙），不用短剧付费墙。

【数据与内容规则】Prompt 全文可看，不拦截。商业化在制作。
放大播放 共用播放页 idea-view / viewer

【页面元素】全屏视频、时长/画质、作者或段数、cast、prompt、进度条；多段 shot chips；Extend + Remix。

【交互说明】Inspiration 与 My Remixes 点 clip 进入同一套样式。模糊样例放大后仍播马赛克片。
Remix 自己的 clip My Remixes

【交互说明】对结果不满意可 Remix：带入 Creation（角色+prompt）再生成。Extend 仍为尾帧续写合并。

【功能逻辑】Extend 他人与自己 Remix 提交价一致，走配置。
Creation / Extend 运营预设 create

【功能逻辑】每剧配置多套 castIds+prompt。进页用第一套。刷新换下一套并清空用户自选角色。

【交互说明】↻ 为工具级，可覆盖已选 Intent。
角色选择 create / extend

【页面元素】My Characters 固定；右侧本剧角色横滑点选，最多 3。

【交互说明】@ 仅已选 cast。My Characters 弹窗 Tab：Recent chats / My lovers。

【边界说明】超过 3 人 Toast。
Intent create / extend

【页面元素】输入框下单行横滑 chips，文案可运营配置。

【功能逻辑】方案 B：尽量保留角色；按槽位性别从本剧补女主/男主；重写动作 prompt。Creation 与 Extend 统一。
生成规格 create / extend

【页面元素】5s · 480P ›；弹层 5s/10s、480P/720P。Generate/Extend 主按钮。

【功能逻辑】Guest 先登录；Gems 不足弹 Gems 墙；成功进 My Remixes，生成中不可 Extend。

【页面元素】Extend 顶部左播成片、右尾帧。

9. 异常与边界

场景表现
Guest 点 Generate / Extend登录墙
Gems 不足Gems 墙，不提交
memberOnly + 非 Plus 点 clipunlockBlur 会员墙；列表/放大页马赛克仍可播
plats 不含当前端不展示该示例
生成中不可 Extend
Intent 缺性别角色从本剧池补；仍不足则 Toast
